BẢNG TRA CỨU API ENDPOINTS HOÀN CHỈNH (RESTFUL API CATALOG)
================================================================================

1. Authentication & Users (/api/auth)
- POST /api/auth/login : Đăng nhập bằng username/password -> Trả về JWT Access Token & Refresh Token
- POST /api/auth/register : Đăng ký tài khoản mới (phân quyền Role)
- POST /api/auth/refresh-token : Làm mới Access Token bằng Refresh Token
- POST /api/auth/logout : Đăng xuất & hủy Refresh Token (Yêu cầu Bearer Token)

2. Quản lý Sản phẩm / Hàng hóa (/api/products)
- GET /api/products : Danh sách sản phẩm (hỗ trợ search, group, phân trang, sắp xếp)
- GET /api/products/{id} : Chi tiết sản phẩm kèm thông số kỹ thuật sợi (Specification)
- GET /api/products/{id}/history : Lịch sử toàn bộ các lần nhập/xuất của sản phẩm (ngày, giá, nhà cung cấp, khách hàng, số lượng, invoice, lô hàng)
- POST /api/products : Tạo mới sản phẩm kèm thông số sợi (YarnType, Denier, Filament, TPM, Color, v.v.)
- PUT /api/products/{id} : Cập nhật thông tin sản phẩm và thông số sợi
- DELETE /api/products/{id} : Xóa mềm (soft-delete) sản phẩm

3. Nhà cung cấp & Khách hàng (/api/suppliers & /api/customers)
- GET /api/suppliers : Danh sách nhà cung cấp (hỗ trợ search, filter quốc gia, phân trang)
- GET /api/suppliers/{id} : Chi tiết nhà cung cấp
- POST /api/suppliers : Tạo mới nhà cung cấp
- PUT /api/suppliers/{id} : Cập nhật nhà cung cấp
- DELETE /api/suppliers/{id} : Xóa mềm nhà cung cấp
- GET /api/customers : Danh sách khách hàng (search, country, pagination)
- GET /api/customers/{id} : Chi tiết khách hàng
- POST /api/customers : Tạo mới khách hàng
- PUT /api/customers/{id} : Cập nhật khách hàng
- DELETE /api/customers/{id} : Xóa mềm khách hàng

4. Đơn đặt hàng PO & SO (/api/orders)
- GET /api/orders/purchase : Danh sách Purchase Orders (search, phân trang)
- GET /api/orders/purchase/{id} : Chi tiết PO kèm danh sách sản phẩm, số lượng, đơn giá
- POST /api/orders/purchase : Tạo mới đơn mua hàng PO
- DELETE /api/orders/purchase/{id} : Xóa đơn mua hàng
- GET /api/orders/sales : Danh sách Sales Orders
- GET /api/orders/sales/{id} : Chi tiết SO kèm danh sách mặt hàng
- POST /api/orders/sales : Tạo mới đơn bán hàng SO
- DELETE /api/orders/sales/{id} : Xóa đơn bán hàng

5. Quản lý Lô hàng - Shipment (/api/shipments)
- GET /api/shipments : Danh sách lô hàng (filter loại NK/XK, trạng thái, phân trang, sort)
- GET /api/shipments/{id} : Chi tiết lô hàng kèm danh sách sản phẩm, invoices, packing lists, chứng từ
- POST /api/shipments : Tạo mới hồ sơ lô hàng
- PUT /api/shipments/{id} : Cập nhật thông tin lô hàng
- PATCH /api/shipments/{id}/status : Cập nhật trạng thái lô hàng (Draft -> PreparingDocuments -> BookingRequested -> InTransit -> Arrived -> CustomsCleared -> Completed)
- DELETE /api/shipments/{id} : Xóa mềm lô hàng

6. Chứng từ Hóa đơn & Đóng gói (/api/invoices & /api/packinglists)
- GET /api/invoices : Danh sách Invoice (search, filter theo lô hàng shipmentId, phân trang)
- GET /api/invoices/{id} : Chi tiết Invoice kèm các dòng sản phẩm chi tiết
- POST /api/invoices : Tạo Invoice (tự động tính tổng tiền từ items)
- DELETE /api/invoices/{id} : Xóa Invoice
- GET /api/packinglists : Danh sách Packing List
- GET /api/packinglists/{id} : Chi tiết Packing List (kiện hàng, trọng lượng gross/net, container, số lot)
- POST /api/packinglists : Tạo Packing List
- DELETE /api/packinglists/{id} : Xóa Packing List

7. Quản lý File & Tài liệu Đính kèm (/api/documents)
- POST /api/documents/upload : Upload tài liệu đính kèm (multipart/form-data: file, category, entityType, entityId, shipmentId, description)
- GET /api/documents : Danh sách tài liệu (filter category, shipmentId, entity)
- GET /api/documents/{id}/download : Tải file về máy
- DELETE /api/documents/{id} : Xóa file tài liệu

8. Dashboard & Thống kê (/api/dashboard)
- GET /api/dashboard : Trả về dữ liệu tổng hợp:
  + Tổng số lô nhập khẩu, xuất khẩu
  + Tổng giá trị kim ngạch nhập khẩu, xuất khẩu ($ USD)
  + Tổng số sản phẩm, nhà cung cấp, khách hàng
  + Số lô hàng đang xử lý (Pending)
  + Danh sách 10 lô hàng mới nhất kèm tiến độ
  + Biểu đồ giá trị nhập/xuất theo từng tháng trong năm

9. Tìm kiếm Global (/api/search)
- GET /api/search?keyword={query}&entityType={all|product|shipment|supplier|customer|invoice} :
  Tìm kiếm nhanh tức thì trên toàn bộ hệ thống.

KẾ HOẠCH CHI TIẾT GIAI ĐOẠN 2: NGHIỆP VỤ XUẤT NHẬP KHẨU CHUYÊN SÂU
================================================================================
1. Quản lý Booking & Container Tracking
- Entity: Booking (Số Booking, Hãng tàu, Đại lý forwarder, Tàu/Chuyến vessel/voyage, Ngày ETD cảng đi, Ngày ETA cảng đến, Closing time, Hạn nộp SI, Free time Demurrage/Detention tại cảng đến).
- Entity: Container (Số container, Số chì seal, Loại container 20DC/40DC/40HQ/Reefer, Nhiệt độ/thông gió nếu có, Trọng lượng bì tare weight, Tình trạng rỗng/đầy hạ bãi).
- Tính năng: Cảnh báo tự động khi tàu sắp cập cảng (ETA <= 3 ngày), cảnh báo sắp hết hạn Demurrage/Detention.

2. Tờ khai Hải quan & Tài khoản Hải quan (Customs Declarations)
- Entity: CustomsAccount (Mã doanh nghiệp, Chi cục hải quan mở tờ khai, Chữ ký số/Token USB ngày hết hạn, Mật khẩu hệ thống VNACCS).
- Entity: CustomsDeclaration (Số tờ khai, Loại hình nhập khẩu E21/A11/A12/E31/B11..., Chi cục hải quan, Phân luồng: Xanh/Vàng/Đỏ, Ngày đăng ký, Ngày thông quan).
- Entity: CustomsDeclarationItem (Dòng hàng tờ khai, Mã HS Code 8 số, Tên hàng theo biểu thuế, Thuế suất NK, Thuế suất VAT, Tiền thuế phải nộp, Trạng thái nộp thuế).

3. Quản lý Biểu thuế & HS Code
- Bảng biểu thuế hải quan Việt Nam: Tra cứu thuế suất ưu đãi thông thường (MFN), thuế ưu đãi đặc biệt (Form E - ACFTA, Form D - ATIGA, Form AK/VK, CPTPP, EVFTA).
- Cảnh báo điều kiện áp dụng C/O hợp lệ để được hưởng thuế suất ưu đãi đặc biệt.

4. Module Import dữ liệu Excel tự động (Tương thích mẫu file thực tế)
- Phân tích và nạp trực tiếp từ file Excel của nhà máy/nhà cung cấp như mẫu `06-08-2026/LONG CHENG WU.xlsx`:
  + Sheet Invoice: Tự động trích xuất Invoice No, Date, Term, Total Amount, từng dòng SKU, Unit Price.
  + Sheet Packing List: Tự động trích xuất Gross Weight, Net Weight, Số kiện Roll/Carton, Số Container.
  + Sheet Specs: Trích xuất các chỉ số Denier/Filament/Color đưa vào cơ sở dữ liệu.

KẾ HOẠCH CHI TIẾT GIAI ĐOẠN 3: TÍNH GIÁ VỐN, THANH TOÁN & QUẢN LÝ NÂNG CAO
================================================================================
1. Tính giá vốn hàng nhập khẩu (Landed Cost Allocation)
- Tập hợp toàn bộ chi phí phát sinh của lô hàng:
  + Tiền hàng (FOB/CIF invoice)
  + Cước vận chuyển quốc tế (Ocean Freight / Air Freight)
  + Phí Local charges tại cảng đi và cảng đến (THC, D/O, CIC, CFS, Seal, vệ sinh container...)
  + Chi phí làm thủ tục hải quan, kiểm tra chuyên ngành
  + Thuế nhập khẩu không được hoàn lại
  + Cước vận tải nội địa từ cảng về kho nhà máy (Trucking)
- Cơ chế phân bổ chi phí về từng mã sản phẩm:
  + Phân bổ theo Giá trị (Value-based)
  + Phân bổ theo Trọng lượng thực (Weight-based)
  + Phân bổ theo Thể tích CBM (Volume-based)
- Kết quả: Tính chính xác Đơn giá vốn bình quân (Landed Unit Cost) cho từng kg sợi nhập kho.

2. Quản lý Thanh toán & Dòng tiền XNK
- Theo dõi các mốc thanh toán: Tạm ứng (Deposit), Thanh toán khi có vận đơn B/L copy, Thanh toán khi hàng đến (Arrival), Thanh toán trả chậm theo LC/TT.
- Theo dõi chênh lệch tỷ giá ngoại tệ (USD, EUR, CNY sang VND) tại các thời điểm nhận hóa đơn và thời điểm chuyển khoản ngân hàng.

3. Quy trình phê duyệt & Phân quyền nhiều cấp (Approval Workflow)
- Quy trình duyệt PO mua hàng: Nhân viên tạo -> Trưởng phòng XNK thẩm định -> Ban Giám Đốc duyệt.
- Quy trình duyệt thanh toán tiền hàng và thuế hải quan: Kế toán kiểm tra chứng từ -> Giám đốc tài chính phê duyệt.

4. Tích hợp Hệ thống Kế toán & Thông báo tự động
- Xuất file dữ liệu hóa đơn nhập mua hàng vào phần mềm kế toán MISA SME / MISA AMIS.
- Gửi thông báo tự động qua Email / Telegram / Zalo ZNS khi lô hàng đổi trạng thái, khi có tờ khai thông quan, hoặc khi tàu cập cảng.
- Cơ chế sao lưu tự động PostgreSQL định kỳ hàng ngày (pg_dump) và đẩy lên cloud storage.
